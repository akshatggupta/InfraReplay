# v7 — CLI Completeness + Export/Import

## Goal

A recording should leave one instance as a single file and replay on
another.

## What is real

- **Bundles** (`infrareplay/recording/portable.py`) — one JSON document
  carrying its own `bundle_version` and `schema_version`, the recording
  metadata and every event. Nothing else is needed to replay it.
- **Import is forgiving where it can be.** An id that already exists is
  re-keyed (recording and events get fresh ids, links remapped) instead of
  refused. An event written against an older `schema_version` is upgraded
  through `infrareplay.schema.migrations`.
- **Validate before import** — `infractl recordings validate f.json`
  answers "would this import?" without writing anything.
- **Projects** — `infractl projects list` / `GET /api/projects`.

## DoD

```bash
infractl recordings export rec_71bd -o checkout.json
infractl recordings validate checkout.json
valid  rec_71bd  16 events  schema v1

# on another instance
infractl recordings import checkout.json
infractl replay <new-id> --target mock
```

Verified by `tests/integration/test_portable.py`.
